Temporally-Weighted, Cost-Sensitive Random Forest

A decision-support module for the laboratory information system. It reads a patient's history for a single laboratory test and forecasts the direction of the next result (Increasing, Decreasing or Stable), so medical technologists can see physiological shifts developing before they breach static reference limits.
